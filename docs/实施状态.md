# 实施状态

## 已编码

- Vue 3 + Vite + TypeScript 用户 H5、桌面适配、四个主要入口。
- 公共地图适配器、空地图状态、水域筛选、详情、公开入口导航。
- 实际取景拍照、定位、鱼种选择、笔记、IndexedDB 草稿。
- 私人素材、公开分享、原文件下载、分享卡。
- 无人工审核的即时点亮、基础图片去重、UUID 幂等。
- 2km 代表点覆盖聚合（尚非水域多边形交集）。
- 活动任务、三榜、积分规则快照、称号、奖励说明和公示。
- 管理员水域 / 规则 / 系统配置、新水域采纳、记录撤销、审计和导出。
- 地图与天气统一管理入口、天气动态配置及连接测试、天气密钥加密存储和脱敏回显。
- File 持久化、可选 PostgreSQL JSONB 仓储、Docker 配置。

## 有意延后

- **贵州省界校验最后实现，当前不拦截省外坐标。**
- 人工审核。
- 数据库实际部署、高德及天气账户配置与联调。
- 微信 / 手机号真实认证；当前只有明确标记的本地体验账号和管理员密码登录。

## 后续能力与限制

- 水域多边形裁剪、精确地图面状覆盖、独立鱼获热度。
- 对象存储驱动、孤立素材清理、留存期限和彻底删除。
- 多实例会话、关系表拆分、PostGIS 索引、分页和大数据优化。
- 三段拖拽抽屉、返回键关闭浮层和更多动态效果。
- Service Worker、完整 PWA 安装资源、微信 / 抖音真机适配。
- 天气失败自动重试和历史天气补取；当前失败后保留 failed，不阻塞提交。
- 站内通知列表、礼物领取登记页面、不可变积分冲正账本。
