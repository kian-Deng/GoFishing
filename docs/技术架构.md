## 前端模块边界

应用外壳只承担导航、全局消息和登录。业务页面通过组件组合；抽屉采用 Teleport 和 Transition。水域详情不直接依赖地图 SDK，地图通过选择事件传出 waterId；地图视图和出钓表单使用 KeepAlive 保留状态。

视图路由对应 `/`、`/record`、`/activity`、`/library`、`/admin`、`/share/:id`。已预留组件分层，后续可将活动 / 素材内容装入全屏抽屉；当前浮层为统一样式组件，各页面自己管理开关，浮层层级、焦点与背景滚动统一管理，尚未完成三段拖拽吸附及浏览器返回键关闭浮层。

目前 Manifest 提供桌面启动配置，尚未包含 Service Worker、离线地图或完整平台安装资源。没有虚假“离线提交成功”。

## 数据与事务

Repository 提供 read / mutate。File 实现单进程串行写入，临时文件 + rename 替换，异常不落入半次业务写入。只能单实例运行，不能多容器共享并发写 JSON。

PostgreSQL 首版用 `fishing_state(id=1,payload JSONB)`，行级 FOR UPDATE + 事务串行保护全状态修改，提供可运行的后配数据库路径。尚未拆关系表、建空间索引或使用 PostGIS；数据增大前应迁移 users / waters / trips / assets / ledger 等独立表和索引。大数据统计和分页同属后续优化，当前查询主要面向小规模试运行。

记录保存规则快照和点亮时间；积分由有效数据派生、ID = tripId:type，撤销后可重算，审计保留变更原因。没有冒称已完成不可变积分事件账本。

## 公私分离

- 精确坐标只在本人记录接口和管理接口提供；公共水域是管理员维护的代表点。
- 新水域申请采纳的公开代表点需粗化后展示，不能直接把用户精确下竿坐标当公开入口。
- 原文件私密，公开图经解码验证和重编码去元数据；不能自动识别照片画面本身写着的坐标。
- Cookie 为 HttpOnly、SameSite=Strict；正式 HTTPS 设 Secure。写接口检查 Origin，登录 / 写操作有基础频率限制。
- 会话存在 API 进程内，重启失效；多实例与真实账号认证需后续共享会话 / 会话数据库。
- 管理员密码来自环境配置，没有默认密码，不下发浏览器。
- 高德 JS Key / JS 安全配置本来用于浏览器，需控制台域名限制；高德服务端 Key、和风密钥不返回前端。

## 外部适配器

高德 MapCanvas 动态加载 JS API，并将 WGS84 定位 / 档案转换为高德展示坐标；公共地图只展示水域代表点和聚合状态，不绘制用户精确圆。导航链接明确声明 WGS84。

天气当前提供 disabled / QWeather 两种选择，调用超时后返回 failed，不影响记录保存。保存观测时间和服务商，避免把后来当前天气当作旧出钓时的真实天气。失败重试与历史补取能力以实施状态文档为准。

天气管理接口：管理员 GET /api/admin/weather 获取脱敏状态，PATCH /api/admin/weather 保存配置，POST /api/admin/weather/test 测试已保存配置。密钥 AES-256-GCM 加密持久化；主密钥在 DATA_DIR/.config.key。仅允许 *.qweatherapi.com 服务域名，禁止任意 URL，避免配置形成内网请求代理。管理台未保存时使用环境变量，保存后采用后台配置。

图片本地上传持久化目录已实现；对象存储预留 Asset 的逻辑编号，后续通过存储接口接入，不改变记录对素材 ID 的引用。

## 拍摄真实性边界

前端现场取景使用 getUserMedia，不用 capture 上传控件；相册来源明确隔离。服务端拍摄令牌、图片解码、归属检查和规范化内容哈希去重提供基础校验，但普通 H5 无法证明客户端没有被修改或排除摄像头翻拍。后续可按需要增加风控、投诉和审核，不把当前方案宣传为强防作弊。
